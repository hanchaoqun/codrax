下载安装

下载 CODRAX

这里提供 Linux 和 macOS 发布包。每个包只包含 codrax 二进制、codrax.yaml.example、 providers.yaml.example 和 docs/user_guide.md，不附带第三方依赖或安装脚本。

选择适合你的版本

Linux 服务器或容器 下载 codrax-linux-amd64.tar.gz。二进制通过 musl 静态链接，适合 x64 Linux 环境直接运行。
macOS 开发机 下载 codrax-macos-universal.tar.gz。universal 二进制，同时支持 Apple Silicon 和 Intel。

发布包

Linux

Linux x64 静态版

适合服务器、容器和远程终端环境，二进制由 musl 静态编译，不依赖系统 glibc 版本。

下载 Linux x64
包内容
codrax codrax.yaml.example providers.yaml.example docs/user_guide.md
bash 
tar -xzf codrax-linux-amd64.tar.gz
cd codrax-linux-amd64
cp providers.yaml.example providers.yaml
chmod +x ./codrax
./codrax version
运行建议

常用外部工具

Codrax 可独立启动，但代码搜索与变更流程通常会用到 git / ripgrep / grep / findutils / patch，这些工具不随发布包分发。

Debian / Ubuntu
sudo apt-get update
sudo apt-get install -y git ripgrep grep findutils patch bash

首次配置

第一次运行前至少复制 providers.yaml.example，填入模型地址、模型名和密钥。

bash
cp providers.yaml.example providers.yaml
$EDITOR providers.yaml
macOS

macOS Universal

适合本地开发机和终端环境。universal 二进制，Apple Silicon 和 Intel macOS 都可直接运行。

下载 macOS
包内容
codrax codrax.yaml.example providers.yaml.example docs/user_guide.md
zsh / bash 
tar -xzf codrax-macos-universal.tar.gz
cd codrax-macos-universal
cp providers.yaml.example providers.yaml
xattr -d com.apple.quarantine ./codrax 2>/dev/null || true
./codrax version
运行建议

架构检查

想确认当前机器架构或二进制内容，可以用下面的命令查看。

zsh
uname -m
lipo -info ./codrax

常用外部工具

建议准备 git 和 ripgrep。若系统没有命令行开发工具，可先安装 Xcode Command Line Tools。

zsh
xcode-select --install
brew install ripgrep

补充说明

包内容固定：codrax、codrax.yaml.example、providers.yaml.example、docs/user_guide.md。不再放入依赖压缩包、安装脚本或其它工具。

Linux 构建要求：Linux x64 包必须来自静态编译；发布侧用 make release 时会以 musl-gcc 构建 dist/codrax-linux-amd64 后再打包。

安装完成后第一件事是打开 providers.yaml 填入模型地址、模型名和密钥；更完整的配置、日志和 trace 用法见 使用手册。

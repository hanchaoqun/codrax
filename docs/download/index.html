Linux / macOS 发布包

按系统和 CPU 架构下载。Linux 使用静态编译版本，macOS 使用原生编译版本。

发布包是最小可运行布局：二进制和配置样例放在包根目录，Markdown 用户手册放在 docs/user_guide.md。如果你需要 git、ripgrep、patch 等外部工具，请按目标系统自行安装。

Linux 服务器或容器 下载 codrax-linux-amd64.tar.gz。该二进制通过 musl 静态链接，适合 x64 Linux 环境直接运行。
macOS 开发机 下载 codrax-macos-universal.tar.gz。包内是 macOS universal 二进制，同时支持 Apple Silicon 和 Intel。

Linux x64 静态版

适合服务器、容器和远程终端环境。Linux 发布包只包含 Codrax 自身产物和文档配置样例，二进制由 musl 静态编译。

下载 Linux x64

包内固定包含以下内容，不包含额外依赖、安装器或脚本。

  • codrax 静态二进制
  • codrax.yaml.example
  • providers.yaml.example

Bash
tar -xzf codrax-linux-amd64.tar.gz
cd codrax-linux-amd64
cp providers.yaml.example providers.yaml
chmod +x ./codrax
./codrax version

常用外部工具

Codrax 可以启动，但代码搜索和变更流程通常会用到 git / ripgrep / grep / findutils / patch。这些工具不随发布包分发。

Debian / Ubuntu: sudo apt-get update sudo apt-get install -y git ripgrep grep findutils patch bash
RHEL / Rocky / CentOS: sudo yum install -y git ripgrep grep findutils patch bash
Alpine: sudo apk add --no-cache git ripgrep grep findutils patch bash

首次配置

第一次运行前至少复制 providers.yaml.example，填入模型地址、模型名和密钥。需要调整运行时参数时再复制 codrax.yaml.example。

cp providers.yaml.example providers.yaml $EDITOR providers.yaml cp codrax.yaml.example codrax.yaml $EDITOR codrax.yaml
macOS
macOS Universal

适合本地开发机和终端环境。请按芯片选择对应包，包内同样只包含 Codrax 编译结果、配置样例和 Markdown 用户手册。

  • codrax macOS 二进制
  • codrax.yaml.example

zsh / Bash

架构检查

如果你想确认当前机器架构或二进制内容，可以用下面的命令查看。

uname -m lipo -info ./codrax

常用外部工具

建议准备 git 和 ripgrep。如果系统没有命令行开发工具，可先安装 Xcode Command Line Tools。

xcode-select --install brew install ripgrep
展开补充说明

包内容固定： codrax、codrax.yaml.example、providers.yaml.example、docs/user_guide.md。除此之外不再放入依赖压缩包、安装脚本或其它工具。

Linux 构建要求： Linux x64 包必须来自静态编译，发布侧使用 make release 时会用 musl-gcc 构建 dist/codrax-linux-amd64 后再打包。

安装完成后的第一件事 是打开 providers.yaml，填入你的模型地址、模型名和密钥；更完整的配置说明、日志和 trace 的使用方法，请直接看上面的 使用手册。

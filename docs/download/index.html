双通道安装 · 按环境选择

先判断环境，再选入口。能在线就走短命令；不能在线就直接下载离线总包。

短命令方案会自动检查依赖、按需安装并显示进度；如果企业网关会拦截脚本文本入口，或者目标环境根本不能直连 codrax.net，就不要再反复尝试在线安装，直接改走离线总包。

能直接访问 codrax.net 选“在线安装”。复制一条短命令执行即可，依赖检查、下载和覆盖更新都会自动完成。
代理返回 403，或去掉代理也连不通 选“离线总包安装”。先在可访问机器下载总包，再拷到目标机本地解压并执行里面的安装脚本。
Windows
Windows x64

适合本地 PowerShell、CMD 和常规开发机环境。脚本会把程序安装到当前用户目录，并把命令入口加入 PATH。

在线安装

短命令

适合可以直接执行远程安装脚本的环境。建议在 PowerShell 中执行。这条路径不需要先下载任何离线包。

PowerShell
查看在线脚本 
$p=Join-Path $env:TEMP 'codrax-install.ps1'; iwr 'http://codrax.net/install.ps1' -OutFile $p -UseBasicParsing -UserAgent 'Mozilla/5.0'; & powershell -ExecutionPolicy Bypass -File $p

离线总包安装

一包式
下载离线总包

适合会拦截脚本文本入口，或者目标机器根本不能直连 codrax.net 的环境。先在可访问机器下载 Windows 离线总包，再把它解压到目标机的 下载 目录，最后在目标机本地执行。

  • 先下载 Windows 离线总包
  • 再拷到目标 Windows 机器的 Downloads 目录
  • 解压后目录里已经带安装脚本和依赖包
  • 最后在本机 PowerShell 执行
PowerShell
查看本地脚本 
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Downloads\codrax-windows-amd64-offline\install-local.ps1"

也就是先下载 codrax-windows-amd64-offline.zip，把它解压成 C:\Users\你的用户名\Downloads\codrax-windows-amd64-offline\，再直接复制执行上面的命令。

展开手动依赖与手动启动

手动准备依赖

如果你不想跑一键脚本，也可以先自己装好依赖。Windows 上最省事的是先装 Portable Git 或 Git for Windows，它会把 git / sh / bash / grep / find / patch 一起补齐，再额外装 ripgrep。

Portable Git: ./PortableGit-2.54.0-64-bit.7z.exe
ripgrep: ./ripgrep-15.1.0-x86_64-pc-windows-msvc.zip
git --version sh -c "exit 0" bash -lc "exit 0" grep --version find --version patch --version rg --version

手动启动

把压缩包解压到任意目录，首次把 providers.yaml.example 复制成 providers.yaml，再填入你的模型配置。

PowerShell: cd C:\tools\codrax Copy-Item .\providers.yaml.example .\providers.yaml .\codrax.exe
Linux
Linux x64 静态包

适合服务器、容器和远程终端环境。安装脚本会优先补齐常用依赖，再把静态链接版本装进你的用户目录。

在线安装

短命令

适合可以直接执行远程安装脚本的环境。请在 Bash 中执行。这条路径不需要先下载任何离线包。

Bash
查看在线脚本 
wget --user-agent="Mozilla/5.0" -qO- http://codrax.net/install.sh | bash

离线总包安装

一包式
下载离线总包

适合会拦截脚本文本入口，或者目标机器根本不能直连 codrax.net 的环境。先在可访问机器下载 Linux 离线总包，再把它解压到目标 Linux 机器的 ~/Downloads 目录，最后在目标机本地执行。

  • 先下载 Linux 离线总包
  • 再拷到目标 Linux 机器的 ~/Downloads 目录
  • 解压后目录里已经带安装脚本和依赖包
  • 最后在本机 Bash 执行
Bash
查看本地脚本 
bash "$HOME/Downloads/codrax-linux-amd64-offline/install-local.sh"

也就是先下载 codrax-linux-amd64-offline.tar.gz，把它解压成 ~/Downloads/codrax-linux-amd64-offline/，再直接复制执行上面的命令。

展开手动依赖与手动启动

手动准备依赖

Linux 侧的最佳状态建议至少具备 git / ripgrep / grep / findutils / patch。下面给的是最常见的安装方式。

Debian / Ubuntu: sudo apt-get update sudo apt-get install -y git ripgrep grep findutils patch bash
RHEL / Rocky / CentOS: sudo yum install -y git ripgrep grep findutils patch bash
Alpine: sudo apk add --no-cache git ripgrep grep findutils patch bash

手动启动

解压后进入目录，把示例配置复制成正式配置，再运行静态链接二进制即可。

tar -xzf codrax-linux-amd64-musl.tar.gz cd codrax-linux-amd64-musl cp ./providers.yaml.example ./providers.yaml chmod +x ./codrax ./codrax
展开补充说明

普通环境方案 会自动检查依赖、按需安装、覆盖更新 Codrax；已有的 providers.yaml 和 codrax.yaml 不会被覆盖。

受限环境方案 现在已经是一包式离线总包，不再要求你自己分别下载脚本、主程序包和依赖包。如果你的环境走代理会被 403，去掉代理又直连卡住，这就说明它应该直接走离线总包安装。

离线总包里已经包含：本地安装脚本、Codrax 主程序包，以及脚本会优先使用的依赖包。Windows 总包内含 Portable Git 和 ripgrep；Linux 总包内含 ripgrep。如果目标机仍缺 git / grep / find / patch 这类基础工具，请继续参考上面的手动说明。

安装完成后的第一件事 是打开 providers.yaml，填入你的模型地址、模型名和密钥；更完整的配置说明、日志和 trace 的使用方法，请直接看上面的 使用手册。

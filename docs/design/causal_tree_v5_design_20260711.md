## 1. 首要架构决策:HTML 是否脱离字符网格(终局论证)〔骨架·方案3 §0,吸收方案2 C.0 判据表与评审2 结论〕

论证要点(终局):

1. **v3 用户裁定原文**:「0 mermaid + 等宽 ```text fence 是三端逐字节一致的长期正确路线」。方案 B 是正面推翻,且其收益(浏览器自动换行、比例字体、真 gauge)恰是 v2→v3 用血换掉的东西——第二布局引擎 = multi-view 病的结构根。
2. **本仓文化红线**:「同一 typed 表两列单源禁手工双同步」。双渲染器是"手工双同步"的最大化形态;方案1 自称的"internal/render 终端面零波及"经评审3 证伪(新增 typed block 必须在 render/answerdoc.go block switch 加臂,validators 拒未知 kind)。
3. **支持工作流资产**:HTML textContent == 终端形 == markdown 落盘,客户回访、贴工单、跨面 diff 全部依赖这一点。
4. **HTML 病的实际根因不需要 B**:36/36 icon 裁切 + 16 处 ❶⧖ 互挤的物理事实是"符号墨迹 9–13.8px > 1ch≈7.2px 格"。根治手段是**给记号 2 格网格预算(文法层)+ 2ch 信封(装饰层)**,不是布局引擎更换,更不是 scale 调参(scale≤1.15 仍裁切、注释 ~1.22x 与代码 1.15 漂移=调参路线终局,评审2 仓内核实 server.go:558-575)。
5. **诚实边界**:三面**信息等价 = 字节等价**;**视觉网格等价只承诺终端与自家 HTML 两面**。第三方 markdown 查看器(GitHub 等)的 CJK 对齐不受控,如实声明,不假承诺。
6. **方案1 收益的可移植部分已移植**(T-5):E# 锚链、sticky 区段头、序数染色、a11y 三属性、行 hover——全部是纯属性/纯 CSS 装饰,不动字节。不可移植部分(真 gauge、HTML 单面全名不截断)经权衡放弃:其收益依赖第二布局权威,代价按 C-1 裁决不可摊销;全名诉求改由双行主行形在三面同时解决(B.0)。

## A. 设计原则(10 条)〔骨架·方案3 P1–P8;P9/P10 移植〕

- **P1 单一权威**:fence 字节是唯一布局权威;终端/markdown 消费原字节,HTML 只做装饰性增强(textContent 不变量 + 机械字节 diff pin),不存在第二布局引擎。
- **P2 最坏形先行**:宽度、行数、折叠、拆行参数全部由最坏形(60+ 行、48+ cell 复合名、全通道混布、⊘ 深链、退化窗)闭式推导并给出确定性上界(单树 fence ≤ ~100 物理行,见 E.2);常规形是最坏形策略的自然退化,不设特例分支;同输入必同输出,零随机零启发。
- **P3 槽位恒定**:同族行的槽序(rails→记号场→名字场→bar→值→%→保留记号→E#)与列位置全树恒定;信息量变化只改变**行数**,永不改变槽序或列位。记号场**恒 4 格**(C-2)使徽章列、glyph 列、名字列三列全树垂直对齐,且无"有席/无席树列位平移"的非局部依赖。
- **P4 完整性 outrank 美观**(继承 T1/PTV4):三要素(词+值+证据)与保留记号(⚠实际/⚠跨窗/⊘链止/[E#])永不截断、永不下移、永不折叠;溢出由确定性拆行吸收;极端仍超宽时如实渲染。
- **P5 折叠 = 移席不隐匿**:一切折叠行都是指向无损明细表的计数指针(N + 极值 + 代表名 + E#);折叠不制造任何三面不可达信息;HTML 不引入隐匿型交互折叠(§29.9 保全,交互层 P3 未裁不排)。
- **P6 记号 2 格制,几何解非调参**:所有非 ASCII 语义记号(状态 glyph、❶..❺ 徽章、区段记号)在字符网格占"记号格+伴随空格"两格;HTML 以 2ch 信封承接墨迹(算术:2ch=14.4px ≥ 实测最大墨迹 13.8px,墨迹高 < 行盒,overflow:visible 永不触邻行——T-3);scale 族与 overflow:hidden 整体退役。bar 块元素(█▒░)是唯一例外(块字形设计即满格,保持 1ch)。
- **P7 口径词贴值**:任何非默认口径的数值(跨线程累计/合计/union/单次最大/折算),其口径词必须与数值**同行同视野**且 verbatim 三面同词(T-4:不造短形、不 fork 词面);解释性延伸(密度、构成、来源)确定性下沉行 2/行 3。墙钟不可加和词面原样保全。
- **P8 图例 = 承诺面**:出场记号必有条;v5 新 mark(↳ 双行接续、区段头计数注、跨窗披露、双视图并席※待裁)各带图例条进目录哨兵;**识别闭集与发射闭集单源**——preview 树头识别以 typed info token 为硬门(T-2),生成侧头形闭集导出为 legacy fallback 白名单+完备性哨兵(根治 ⊘ 树 3/14 裸 pre)。
- **P9 零新语义面优先**〔移植·方案2〕:v5 新 glyph 恰 1(↳,过 EAW 审查门)、新用户面词面 ≤4 条且全部图例挂账、零删词面;既有 verbatim pin(`(跨线程累计,非墙钟)`、`占窗>100%`、盲区二判据词等)除重裁档明列项外一律不动。
- **P10 精确信号驱动一切新分支**:v5 全部新判定(恒 4 记号场=无条件、双行形阈=单一宽度比较、>120% 跨窗=单一数值比较、一段一席=typed 段集指纹相等)是精确信号;嗅探/相似度类信号只许做 legacy fallback 软路径(CLAUDE.md 红线在渲染域的映射)。

每条命令只生成一个报告文件；版本、trace 强指纹与 source lock 已在报告头。常规回传
前两个文件，IO 或 Berlin 专项按场景各加对应单个文件；UX 问题只附已有的单个 HTML。不要回传凭据或整个
`.codrax/blob`。完整规则见 `docs/design/trace_witness_collection_playbook_20260710.md`。

## 维护规则

1. 每次相关提交必须在本账本更新状态、commit SHA（合入后补）与验证命令；不得只在聊天里销项。
2. fail-close 项只有在“错误时长不会铸造 + caveat 可见”时可写“正确性防线已修”；只有解析了稳定 typed identity 并有正/负/歧义 pin，才可写“精确能力已修”。

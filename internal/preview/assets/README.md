# Embedded Mermaid Asset

`mermaid.min.js` is vendored from the npm package `mermaid@11.12.0`:

https://cdn.jsdelivr.net/npm/mermaid@11.12.0/dist/mermaid.min.js

The asset is embedded into the Codrax binary for the local markdown
preview server so browser rendering does not depend on a CDN or external
network access. Mermaid is distributed under the MIT license; see
`MERMAID_LICENSE`.
